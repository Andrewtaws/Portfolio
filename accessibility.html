Accessibility

Accessibility statement

Accessibility is my specialism, so this site aims to practise what it preaches. It’s built to meet the Web Content Accessibility Guidelines (WCAG) 2.2 at Level AA.

What you can do on this site

  • Use it with a keyboard alone. Every link, button and form field can be reached and shows a clear focus outline.
  • Skip straight to the main content with the “Skip to main content” link.
  • Zoom text up to 400% without content being cut off or needing to scroll sideways.
  • Turn off motion: the small hover and scroll animations stop if your device is set to reduce motion.
  • Use Windows High Contrast and other forced-colour modes.
  • Read descriptions of every meaningful image, including full text versions of the persona cards.

How it was built

  • Semantic HTML with landmarks, a logical heading order and one main heading per page
  • Text and interface colours that meet WCAG AA contrast ratios
  • Links and buttons at least 44 by 44 pixels
  • No content hidden behind hover, no auto-playing media and no time limits
  • Forms with visible labels, clear error messages and an error summary

How it was tested

Every page has been checked with the axe-core automated testing engine against WCAG 2.2 A and AA rules, with keyboard-only testing, and at 320 pixels wide to check reflow.

This statement was last reviewed on 9 November 2026.

Known limitations

  • Case study screenshots show product interfaces as images. Each has a text description, but small details within them may not be described in full.
  • Some very tall screenshots are cropped on the page. A link under each opens the full image.

Feedback

If you find anything on this site hard to use, I’d genuinely like to know. Get in touch and I’ll fix it.
